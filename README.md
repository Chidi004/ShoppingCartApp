# Java Food Shopping Cart
A simple console-based program that asks the user what food they want to buy, how many plates, and the price per plate-then calculates and displays the total cost.

##Features
-Prompts the user for a food name
-Accepts quantity and price per item
-Calculates total cost (quantity x price)
-Displays the result with a Rand(R) currency symbol

##Technologies
-Java
-'Scanner' for console input
